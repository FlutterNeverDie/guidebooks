# 세스코 연구원을 위한 AI 그림책 (CESCO Lab AI Playbook)

> **화학공학·이물 분석 연구원을 위한 실전 AI 그림책 및 업무 에이전트 가이드**  
> 로컬 단일 HTML(`dist/cesco/index.html`)로 엽니다.

---

## 📖 전체 목차

| 권 | 제목 | 핵심 내용 |
|---|---|---|
| **1권** | AI는 어떻게 말을 할까 | 토큰, 확률 기반 단어 생성, 다이얼(파라미터) 학습, 환각의 원리 |
| **2권** | AI와 대화 잘하기 | 컨텍스트 창(실험대), 기억의 비밀, SOP 프롬프트, FT-IR 스펙트럼 임베딩, RAG |
| **3권** | AI가 일을 하게 하기 | 도구 사용(Tool Use), 생각-행동-관찰 에이전트 루프, MCP(USB-C), 안전 장치 |
| **4권** | 내 일에 AI 쓰기 | 보안 신호등, 이물 분석 보고서 요약, 엑셀 정리, 재현성 검증 시험 |
| **5권** | AI가 보는 세상과 앞으로 | 멀티모달 현미경 사진 판독의 한계, 모델 체급 선택, 연구원의 책임 |
| **특강** | AI 에이전트 사용에 중요한 3가지 | 파인튜닝 없이 지침(Hook), 스킬(Skill), 검증(Harness)으로 가르치기 |
| **실전** | 세스코 업무에 녹이기 | 업무 소개, 입력 양식 하나로 3개 안 받고 10분 뒤 고르기, 3일 완성 |

---

## 🛠 아키## 소스와 빌드

- 내용: `books/cesco/volumes/vol1/` ~ `vol7/` (`meta.js`, `chapN.js`, `recap.js`)
- 표지와 머리글 문구: `books/cesco/book_cover.js`
- 공통 엔진: 저장소 루트 `engine/`
- 검사: `node engine/harness.js cesco` (필수 필드, 퀴즈 정답, 긴 대시, 표지 문구)
- 빌드: `node engine/build.js cesco` (검사 통과 뒤 `dist/`에 생성)
- `_archive_외부AI판/`: 2~5권 외부 AI 원본 백업
