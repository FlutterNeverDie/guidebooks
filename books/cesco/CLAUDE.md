# 연구원을 위한 AI 그림책 (메모리에서 옮김 2026-11-09)

필요할 때마다 공부한 것을 그림책으로 정리하는 저장소. 독자는 화공과 졸업, 이물 분석 연구원, 파이썬 기초만. 비유는 실험실 · 이물 분석에서 가져온다 (핵심 비유: 임베딩 = FT-IR 스펙트럼 라이브러리 검색).

## 형식
- **코드는 한 줄도 넣지 않는다.** 왼쪽은 항상 그림 · 애니메이션 · 3D, 오른쪽은 글, 버튼으로 넘기는 펼친 책
- **파일 하나**(`연구원을_위한_AI_그림책.html`)에 모든 권을 담고 왼쪽 책장(책등)으로 이동. 파일을 나누지 않는다
- 빌드: 저장소 루트에서 `node engine/build.js cesco` → `dist/cesco/index.html`. 내용은 `books/cesco/volumes/volN/`(장 하나 = 파일 하나), 공통 엔진은 `engine/`. 예전 `build/engine.html` + `build.py` 방식은 더 쓰지 않는다
- 오른쪽 글은 소제목(h3) + 짧은 문단 + 단계 카드(.steps) + 용어 카드(.cards). 긴 문단 금지
- 확인: Playwright 스크립트로 PC · 폰에서 넘김 확인

## 권 구성
- 1권 완성. 2~5권은 외부 AI가 `2-5권_작성_지침.md`대로 쓰고 Claude Code가 검토(기록은 지침 10절, 원본 `_백업_외부AI판/`)
- 6권 "이상훈 특강": 파인튜닝 대신 커스텀. 지침 System prompt / 스킬 Skill md / 검증 Harness (업계 용어로)
- 7권 실전 "세스코 업무에 녹이기"
- 사용자는 권을 "장"이라고도 부른다("4장" = 4권). 보안 이야기는 4권 1장 한 쪽이면 충분, 다른 곳에 반복하지 않는다
