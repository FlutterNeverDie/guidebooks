# AX 심화편: 품질·규모·신뢰의 설계

중급편 다음 책이에요. 5권 x 5장으로 임베딩 개선, 큰 색인, 그래프 근거, 권한 경계, 여러 작업자의 복구를 다뤄요.

- 원고의 정본은 `volumes/volN/*.js`예요. 직접 수정해요. 비공개 생성기에 의존하지 않아요.
- 실습은 `labs/rag-study/course/a1_embeddings.py`부터 `a5_agents.py`까지예요. A~E가 각 권의 1~5장이에요.
- `python3 labs/rag-study/course/run_all.py`로 실습과 결과를 확인해요. 수치는 실행한 결과만 쓰고 가정·합성·모형의 범위를 바로 밝혀요.
- 작은 선형 순위기 학습은 사전학습 임베딩 모델 파인튜닝이 아니에요. 스칼라 양자화는 PQ가 아니고, LRU 모형은 DiskANN 벤치마크가 아니에요.
- GraphRAG의 일반 개념과 Microsoft GraphRAG 구현을 구분해요. Cypher 매개변수만으로 권한이나 비용이 보장된다고 쓰지 않아요.
- 문서·모델 출력은 권한의 근거가 아니에요. 승인 내용 결합, 데이터 계층 권한, 멱등성의 보장 범위를 구체적으로 적어요.
- 실제 LLM 호출은 기존 로컬 전용 규칙을 따르고 CI·브라우저에서 호출하지 않아요.
- 그림은 360x480 `COURSE` 장면 도구, 그림:글은 1:1.875예요. 공식 자료 링크와 실험의 한계를 포함해요.

- 실제 인코더 학습은 `course/train_embeddings.py`, 색인 이행은 `index_migration.py`예요. `reports/`의 실제 실행과 `a1`의 작은 순위기를 구분해요. 학습 파일 `.cache/`는 공개하지 않아요.
- 동시 예약·승인 소비는 `concurrency.py`의 독립 SQLite 연결로 검사해요. 외부 API의 정확히 한 번을 보장한다고 쓰지 않아요.
